## 1. 개요

### 1.1 배경
회분식(Batch) 화학합성 공정용 소프트웨어를 주로 개발하는 개발자로서, 보유 기술·프로젝트 경험·도메인 전문성을 한곳에 정리해 보여줄 개인 프로필 웹사이트가 필요하다. 일반적인 웹/앱 포트폴리오와 달리 **화학 공정 도메인 + 소프트웨어 엔지니어링**의 교차점이라는 차별점을 명확히 전달하는 것이 핵심이다.

### 1.2 목표
- 방문자가 **30초 안에** "회분식 화학합성 프로그램 전문 개발자"라는 정체성을 파악할 수 있다.
- 주요 프로젝트의 문제·해결·성과를 구조적으로 보여준다.
- 채용 담당자·협업 제안자가 이메일로 쉽게 연락할 수 있다.

### 1.3 비목표 (이번 범위 제외)
- 블로그/CMS 기능
- 로그인, 회원 기능
- 다국어(영문) 지원 → 추후 검토

## 3. 핵심 메시지 (포지셔닝)

> **"화학 공정을 이해하는 소프트웨어 개발자"**
> 회분식 화학합성 공정의 레시피 관리, 장비 제어, 데이터 수집·분석 프로그램을 설계하고 개발합니다.

### 주요 개발 분야 키워드
- 회분식(Batch) 공정 제어 및 레시피 관리 (ISA-88 개념 기반)
- 반응기 장비 연동 (PLC, OPC UA, Modbus 등)
- 공정 데이터 수집·모니터링·시각화
- 배치 기록(Batch Record) 및 이력 추적
- 합성 실험·생산 자동화

> ※ 실제 사용 기술/표준은 확정 후 수정 필요

## 4. 기능 요구사항

### 4.1 페이지 구성 (싱글 페이지 + 섹션 스크롤)

| # | 섹션 | 내용 | 우선순위 |
|---|---|---|---|
| 1 | Hero | 이름, 한 줄 소개, 주 개발분야, 연락하기 버튼 | P0 |
| 2 | About | 자기소개, 도메인 경험 요약, 개발 철학 | P0 |
| 3 | Expertise | 회분식 화학합성 관련 전문 영역 카드 (3.의 키워드) | P0 |
| 4 | Skills | 언어·프레임워크·통신 프로토콜·DB·도구 분류별 표시 | P0 |
| 5 | Projects | 프로젝트 카드 목록 → 상세(문제/역할/해결/성과/기술) | P0 |
| 6 | Experience | 경력 타임라인 | P1 |
| 7 | Contact | 이메일(lkkkk0515@gmail.com), GitHub 등 외부 링크 | P0 |

### 4.2 세부 요구사항
- **FR-1** 상단 내비게이션에서 각 섹션으로 부드럽게 스크롤 이동한다.
- **FR-2** 프로젝트 카드는 기술 태그로 필터링할 수 있다. (P1)
- **FR-3** 프로젝트 상세에는 공정 흐름도·화면 캡처 등 이미지를 넣을 수 있다.
- **FR-4** 연락처의 이메일은 `mailto:` 링크로 제공하고, 클릭 시 복사 기능도 제공한다.
- **FR-5** 콘텐츠(프로필, 스킬, 프로젝트)는 코드와 분리된 데이터 파일(JSON 또는 Markdown)로 관리해 수정이 쉽도록 한다.
- **FR-6** 다크/라이트 모드를 지원한다. (P1)
- **FR-7** 이력서 PDF 다운로드 버튼을 제공한다. (P2)

### 4.3 보안·기밀 고려
- 회사 기밀에 해당하는 공정 조건, 레시피, 고객사명은 노출하지 않는다.
- 프로젝트 설명은 일반화된 표현과 마스킹된 화면을 사용한다.
