# PRD — 회분식 반응기를 이용한 니켈 나노입자 AI 합성 프로그램

## 1. 개요

| 항목 | 내용 |
|---|---|
| 제품명 | Ni-NP AI Synthesizer (회분식 반응기 니켈 나노입자 AI 합성 프로그램) |
| 목적 | 회분식(batch) 반응기에서 화학적 환원법으로 니켈 나노입자를 합성할 때, **평균 입자 크기 40 nm**를 얻는 레시피(시약 투입량)를 AI가 추천하고, 실험 결과를 학습하며 목표에 수렴시킨다. |
| 사용자 | 나노소재 합성 연구원, 공정 엔지니어 |
| 형태 | Python 데스크톱 GUI(PyQt6) + CLI |

## 2. 배경 및 문제

- 니켈 나노입자 크기는 Ni 농도, NaOH 비율(pH), 환원제(Hydrazine) 비율, 핵생성제(Sodium hypophosphite) 비율에 민감하게 반응한다.
- 변수 간 상호작용이 비선형이어서 시행착오(OFAT) 방식으로는 목표 크기(40 nm)를 맞추는 데 많은 실험 횟수가 필요하다.
- **베이지안 최적화(가우시안 프로세스 + 기대 개선 획득함수)** 를 이용하면 적은 실험 횟수로 목표 크기에 도달할 수 있다.

## 3. 실험 공정 (고정 조건)

| 단계 | 내용 | 조건 |
|---|---|---|
| 1 | 반응기에 **NiSO₄(·6H₂O)** 와 **Water** 투입, 용해 | 상온(25 °C) |
| 2 | **50 % NaOH Solution** 투입 → Ni(OH)₂ 전구체 형성 | — |
| 3 | 교반 혼합 | **150 rpm, 30 분** |
| 4 | **Sodium hypophosphite(NaH₂PO₂·H₂O)** 와 **Hydrazine(N₂H₄·H₂O)** 투입 | — |
| 5 | 교반 환원 반응 | **150 rpm, 1 시간** |
| 6 | 세척·건조 후 입도 측정 (TEM/SEM/DLS) | — |

- 반응 온도: **상온(25 °C)**
- 기본 배치 크기: Water 100 mL (프로그램에서 변경 가능)
- 주요 반응식: `2Ni²⁺ + N₂H₄ + 4OH⁻ → 2Ni⁰ + N₂↑ + 4H₂O` (N₂H₄/Ni 화학양론비 = 0.5)
- 용어 가정: 요구사항의 “Sodium hypophosphate”는 무전해 니켈 공정에서 핵생성제/보조환원제로 쓰는 **Sodium hypophosphite(차아인산나트륨, NaH₂PO₂)** 로 해석한다.

## 4. 최적화 변수 (AI가 조절하는 값)

| 변수 | 의미 | 범위 |
|---|---|---|
| `c_ni` | NiSO₄ 농도 (M, Water 기준) | 0.05 – 0.50 |
| `r_oh` | NaOH / Ni 몰비 | 2.0 – 8.0 |
| `r_hz` | Hydrazine / Ni 몰비 | 0.5 – 6.0 |
| `r_p` | NaH₂PO₂ / Ni 몰비 | 0.0 – 1.0 |

목표: `|평균 입경 − 40 nm|` 최소화 (허용 오차 기본 ±2 nm)

변수 → 실제 투입량 환산 (Water 100 mL 기준):
- NiSO₄·6H₂O (g) = n_Ni × 262.85
- 50 % NaOH (mL) = n_Ni × r_oh × 40.00 / 0.50 / 1.525
- Hydrazine monohydrate (mL) = n_Ni × r_hz × 50.06 / 1.032
- NaH₂PO₂·H₂O (g) = n_Ni × r_p × 105.99

## 5. 기능 요구사항

| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| F1 | 실험 데이터 관리 | 실험 조건 + 측정 입경을 CSV(`data/experiments.csv`)로 저장/조회/삭제/가져오기 | 필수 |
| F2 | AI 크기 예측 | 가우시안 프로세스 회귀로 조건별 입경 예측값과 95 % 신뢰구간 제공 | 필수 |
| F3 | 다음 실험 추천 | 베이지안 최적화(EI)로 40 nm에 가장 빨리 접근할 다음 실험 조건 N개 추천. 데이터 5개 미만이면 라틴 하이퍼큐브 초기 실험 설계 | 필수 |
| F4 | 최종 레시피 | 현재 모델 기준 40 nm에 가장 가깝고 불확실성이 낮은 레시피를 시약 투입량(g, mL)과 공정 절차로 출력 | 필수 |
| F5 | 가상 반응기 시뮬레이터 | 실험 데이터가 없을 때 핵생성·성장(LaMer) 경험식 기반 가상 실험으로 데모/검증 | 필수 |
| F6 | 자동 최적화 데모 | 추천 → 가상 실험 → 재학습 루프를 N회 자동 수행, 수렴 그래프 표시 | 권장 |
| F7 | 시각화 | 최적화 이력(실험 회차별 입경, 40 nm 기준선), 변수별 예측 곡선 | 권장 |
| F8 | CLI | `suggest / add / predict / best / demo / list` 명령 제공 | 권장 |

## 6. AI 모델 설계

1. **입력 정규화**: 4개 변수를 [0, 1]로 스케일링
2. **대리모델(Surrogate)**: Gaussian Process, Matérn 5/2 ARD 커널, 출력은 `ln(입경)`
   - 하이퍼파라미터는 로그 주변우도 최대화(L-BFGS-B, 다중 시작점)
3. **획득함수**: 목표 오차 `|d − 40|`에 대한 Monte-Carlo 기대 개선(EI)
4. **후보 탐색**: 무작위 후보 + 현재 최적점 주변 국소 섭동 후보 → EI 최대 지점 선택, 배치 추천 시 후보 간 최소 거리 유지
5. **최종 추천**: `|예측 − 40| + κ·불확실성` 최소 지점

## 7. 가상 반응기 모델 (시뮬레이터)

실제 데이터가 쌓이기 전 데모·검증용 경험 모델이며 **실제 공정값으로 보정이 필요**하다.

- 환원 속도: `k = k0 · r_hz^1.2 · (r_oh/2)^0.8 · (1 + 3·r_p) · (rpm/150)^0.2 · Arrhenius(T)`
- 전환율: `X = min(1 − e^(−k·t₂), (r_hz + 0.5·r_p)/0.5)`
- 핵 수: `N ∝ k^1.5 · (1 + 8·r_p) · c_ni^0.5 · (rpm/150)^0.3`
- 입경(질량 보존): `d = K · (c_ni · X / N)^(1/3)`, 고농도 응집 보정, 측정 노이즈 약 6 %
- 경향: Hydrazine·NaOH·Hypophosphite ↑ → 핵 생성 ↑ → 입경 ↓ / Ni 농도 ↑ → 입경 ↑

## 8. 사용자 흐름

```
[데이터 없음] → 초기 실험 설계(5회) 추천 → 실험 수행 → 측정 입경 입력
      ↓
[GP 학습] → 다음 실험 추천(EI) → 실험 → 입력 → 재학습  (반복)
      ↓
|d − 40| ≤ 2 nm 도달 → 최종 레시피(투입량 + 절차) 출력
```

## 9. 비기능 요구사항

- Python 3.10+, 의존성: numpy, scipy, pandas, matplotlib, PyQt6 (scikit-learn 불필요)
- 추천 계산 시간: 데이터 100개 이하에서 5초 이내
- 한글 UI, 결과 CSV는 엑셀에서 열 수 있게 UTF-8-SIG 저장

## 10. 성공 지표

- 가상 반응기 데모에서 **15회 이내 실험으로 40 ± 2 nm** 도달
- 실제 실험에서 OFAT 대비 실험 횟수 50 % 이상 감소

## 11. 범위 밖 (향후)

- 입도 분포(PDI) 다목적 최적화, 수율 동시 최적화
- 반응 온도·교반 속도·시간을 최적화 변수로 확장
- 반응기 PLC/센서 연동 자동 실험
